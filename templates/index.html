01 Clone to localhost

Three commands to a running app.

No build step to learn, no compose file to debug. pave setup creates the database, runs the migrations, and lays down the Soniq tables. pave dev starts the server and the Tailwind watcher together. You are looking at real routes, not a placeholder, in under a minute.

{# Terminal card. A flat surface with three window dots and a mono transcript. Prompts are muted, commands are foreground, the result line picks up the primary accent. #}
bash 
$ git clone https://github.com/you/pave my-app
$ cd my-app && pave setup
$ pave dev
→ serving on http://localhost:8000
# when you are ready
$ fab production deploy
