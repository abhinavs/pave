{# Switch. A binary toggle that submits like a checkbox but reads as "on / off" instead of "yes / no". The visual knob is pure CSS via peer-checked - no Alpine - so this works inside a regular form. Like the login remember-me checkbox, callers who need a value to always post should pair the switch with a hidden input of the opposite value above it. Context variables: name - form name and input id (required) label - visible label text (required) checked - bool, pre-selects on value - submitted value when on, default "true" help - secondary help text rendered under the label #}
