{# Checkbox. Real native input wrapped in a label so the entire row is clickable. The check glyph is the Phosphor "check" icon revealed by a peer-checked rule, which means no Alpine state is needed for the pure on/off case. The hidden+real pair pattern (matching login's remember-me) is left to the caller to add when the form must always carry a value. Context variables: name - form name and input id (required) label - visible label text (required) checked - bool, pre-selects the box value - submitted value when checked, default "true" help - small helper text under the row required - bool #}
